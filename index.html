Gamified Wellness Challenge Web Application

A full-stack Node.js, Express, and MySQL web application that gamifies wellness habits. Users are sorted into houses at Year 1, complete wellness challenges to earn points, cast elemental spells, and collect Death Eater & Voldemort badges that boost future rewards.

Node.js Express.js MySQL JWT & bcrypt JavaScript HTML & CSS

Verified Features

  • JWT registration & login with bcrypt password hashing, automatic random House assignment, and Year 1 initialization.
  • Elemental type chart system awarding 1.5× (Strong), 1.0× (Neutral), or 0.75× (Weak) point multipliers on challenge completion.
  • Spell shop & inventory system (`/api/shop/spells`, `/api/shop/buy`) allowing optional spell consumption during challenges.
  • Tiered collectible Badge system (`1.0×` up to `1.4×` bonus) where all Death Eater badges must be owned before unlocking the Voldemort badge.
  • Cooldown enforcement to prevent challenge farming, plus full CRUD challenge reviews.

What I Learned

  • Structuring clean MVC layers (`routes → controllers → models → middleware`) so complex reward calculations stay maintainable.
  • Designing relational MySQL tables for user inventories, completion logs, type charts, and progression thresholds.
  • Securing API endpoints with stateless JWT bearer tokens and custom middleware chains.

Future Improvements

  • Deploy the Express + MySQL stack to a cloud platform with live house leaderboards.
  • Add automated integration tests for multi-step spell and badge multiplier calculations.
